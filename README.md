# RTL Projects
This repository containes a list of projects related to RTL programming and Verification. Individual program and testbenches will be programmed in Verilog and SystemVerilog.

## Projects
1. Simple Calculator (Combinational logic, module instantiation, gate-level and data-flow code)
2. BRAM Cell (Combinational, sequential logic and behavioral code)
3. Traffic Light Simulation (State Machines)
4. Pipelining Demo (Overlapping instruction stages, pipeline hazards)
5. Pipelined ALU (Pipeline timing/throughput vs. a non-pipelined baseline)
6. Simple Pipeline (Basic multi-stage datapath)
7. Synchronous FIFO (Dual-pointer queue, full/empty detection)
8. RISC-V Subset Core (Minimal instruction fetch/decode/execute core)
9. SIMT Core (Naive sequential vs. parallel warp execution)
10. Out-of-Order Core (Tomasulo's algorithm, reorder buffer, OOO vs. in-order vs. pipelined-in-order comparisons)
11. Direct-Mapped Cache (Tag/index decomposition, conflict misses, cache vs. no-cache timing)
12. Set-Associative Cache (2-way associativity, LRU replacement, conflict-miss elimination)
13. Cache Replacement Policies (4-way associative cache comparing LRU, FIFO, NRU, and deterministic random eviction)
14. Cache Replacement Policy Prototypes (Python models of LRU/FIFO cache behavior)
